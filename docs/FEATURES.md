# راهنمای قابلیت‌ها

توضیح کامل کارهایی که ربات انجام می‌ده. نصب و راه‌اندازی در `README.md` است.
متن‌های داخل ربات و مینی‌اپ انگلیسی هستن.

---

## قابلیت‌ها

**منوی اصلی** (`/start`)
- بالای منو یه خلاصه هست: تعداد سرورها (و چندتا روشن)، چندتا نزدیک سقف ترافیک یا بالاتر از اون، هزینه‌ی ماهانه‌ی سرورها (با قیمت‌های دستی) به‌اضافه‌ی اضافه‌ترافیک این ماه، و تعداد الرت‌ها و زمان‌بندی‌ها.
- 📊 **All Servers**: لیست سرورهای همه‌ی اکانت‌ها. دکمه‌ی هر اکانت فقط سرورهای همون اکانت رو نشون می‌ده.
  - کنار هر سرور یه نوار و درصد مصرف ترافیک هست (`▓▓▓░░ 60%`). اگه سرور نود یکی از پنل‌های PasarGuard تعریف‌شده باشه، `🧩اسم‌پنل` کنارش میاد (ربات هر ۱۰ دقیقه لیست نودها رو از پنل می‌خونه).
  - **↕️ Sort**: مرتب‌سازی بر اساس ترافیک (پرمصرف‌ها بالا، پیش‌فرض) یا اسم.
  - **🔥 Near limit**: فقط سرورهایی که ۷۵٪ ترافیکشون یا بیشتر مصرف شده.
- 📸 **Snapshots**، 💸 **Cost Report**، 🌐 **Floating IPs**، 📍 **Primary IPs**
- 🔔 **Alerts & Schedules (n)**: همه‌ی الرت‌های در انتظار و ریست‌های زمان‌بندی‌شده، با دکمه‌ی لغو (و دکمه‌ی ⏸ توقف همه‌ی کارهای خودکار)
- 🩺 **Health**: وضعیت اکانت‌های هتزنر، ⏸ توقف کارهای خودکار، گزارش روزانه (پایین‌تر توضیح داده شده). اگه اکانتی مشکل داشته باشه ⚠️ و اگه کارها متوقف باشن ⏸ کنار دکمه میاد.
- ⏳ **Running now**: کارهایی که همین الان در جریانن (پایین‌تر)

**دستورها** (در منوی دستورهای تلگرام، فقط برای خودت)
- `/find اسم یا IP`: مستقیم صفحه‌ی سرور رو باز می‌کنه. تکه‌ای از اسم یا اول IP هم کافیه (مثلاً `/find web` یا `/find 1.2.3`)؛ اگه چندتا پیدا بشه لیستشون میاد.
- `/servers` لیست سرورها، `/alerts` الرت‌ها و زمان‌بندی‌ها، `/cost` گزارش هزینه، `/health` سلامت و توقف کارهای خودکار، `/running` کارهای در جریان، `/start` منوی اصلی.

**دکمه‌های 📋 کپی**: با یه بار زدن، متن کپی می‌شه: IP سرور، رمز root (بعد از ساخت سرور، Rebuild و Reset Password)، API key نود (وقتی اضافه شدن به پنل ناموفق باشه) و دستور Floating IP.
اگه این دکمه‌ها رو نمی‌بینی، تلگرامت رو آپدیت کن.

**صفحه‌ی هر سرور**
- دکمه‌ها: بالا کارهای پرتکرار (روشن/خاموش، SSH Console، Refresh، Reset Traffic، Reset Schedule، تغییر پلن)،
  بعد **⚙️ Manage** (Rebuild، Snapshots، Rename، Edit Price، Backups، Reset Password، Delete)،
  **🌐 Network** (کپی IPv4/IPv6، Floating IPs، Volumes، Add to Panel) و **📋 Copy IP**.
- مشخصات: لوکیشن، پلن، CPU/RAM، دیسک واقعی، IP، وضعیت، بکاپ
  - اگه قبلاً دیسک رو ارتقا داده باشی، اندازه‌ی واقعی نشون داده می‌شه و کنارش «(plan … GB)» میاد.
- هزینه: هزینه‌ی ماهانه، هزینه‌ی اضافه‌ترافیک (با قیمت هر TB همون لوکیشن)، مصرف ترافیک نسبت به سقف همون سرور با نوار (`▓▓▓▓▓▓░░░░ 60%`)
- اگه سرور نود پنل باشه: «🧩 Node of panel …»
- اگه محافظت روشن باشه «🛡 Protected» و اگه هتزنر سرور رو قفل کرده باشه «🔒 Locked by Hetzner» کنار بکاپ میاد.
- اگه کاری روی سرور در جریان باشه (ریست، تغییر پلن، تغییر IP، یا کار خود هتزنر مثل اسنپ‌شات) یه خط «⏳ …» با مرحله یا درصدش نشون داده می‌شه.
- 🔴/🟢 روشن و خاموش، 💻 SSH Console، 🔄 بروزرسانی
- ♻️ **Reset Traffic**: سرور رو موقتاً می‌بره روی یه پلن دیگه و برمی‌گردونه، تا شمارنده‌ی ترافیک صفر بشه.
  اول یه صفحه‌ی تأیید میاد (پلن، ترافیک، هزینه‌ی اضافه تا الان)؛ با **✅ Yes, reset** شروع می‌شه و سرور چند دقیقه خاموش/روشن می‌شه.
  حین کار فقط یه خط وضعیت نشون می‌ده (مثلاً «Step 3/6: Moving to cx33»)، آخرش خلاصه (ترافیک قبل ← بعد و نتیجه)؛
  لاگ کامل با دکمه‌ی **📜 Details** (تا ری‌استارت بعدی ربات نگه داشته می‌شه).
  اگه برگشت به پلن اصلی ممکن نباشه، ربات سرور رو می‌بره روی پلنی که **سخت‌افزارش از همه به پلن اصلی نزدیک‌تره**
  (هم‌معماری، با دیسک کافی؛ مثلاً cx23 که ۲ هسته و ۴ گیگ رم داره، به‌جای cx33 می‌ره روی cpx22) و سرور **روشن می‌مونه**.
  اگه اون هم جا نداشته باشه، روی همون پلن بزرگ‌تر می‌مونه.
  بعد ربات یه الرت برگشت ثبت می‌کنه که هر وقت پلن اصلی موجود شد خودکار برش گردونه و خبر بده
  (این الرت برخلاف بقیه هیچ‌وقت خودکار بودنش خاموش نمی‌شه، فقط بین تلاش‌ها صبر می‌کنه، حداکثر ۲ ساعت).
  تا وقتی برنگشته، صفحه‌ی سرور می‌نویسه «↩️ Waiting to move back to …».
  ریست بعدی هم اول همون پلن اصلی رو امتحان می‌کنه؛ اگه جا باشه همون یه جابه‌جایی هم ترافیک رو صفر می‌کنه هم سرور رو برمی‌گردونه.
- ⏰ **Reset Schedule**: ریست ترافیک خودکار در ساعت مشخص، به **وقت ایران**.
  تکرار: یک بار (یکی از ۱۴ روز آینده)، هر روز، هر هفته (یک روز هفته) یا هر ماه (یک روز ماه؛ اگه ماه کوتاه‌تر باشه، روز آخرش).
  بعد ساعت و دقیقه رو انتخاب کن (۰۰، ۱۰، … ۵۰). همه با دکمه‌ست، تایپ لازم نیست.
  موقع شروع و پایان هر ریست پیام می‌ده. زمان ریست بعدی در صفحه‌ی سرور و در 🔔 Alerts & Schedules دیده می‌شه.
  اگه ربات سر وقت خاموش بوده و بیش از یک ساعت گذشته باشه، اون نوبت اجرا نمی‌شه (که سرور وسط روز خاموش نشه) و خبر می‌ده.
  هیچ‌وقت دو ریست یا تغییر پلن هم‌زمان روی یه سرور اجرا نمی‌شه.
- 💻 **SSH Console**: اجرای دستور روی سرور از داخل تلگرام.
  اطلاعات ورود با پسورد یا کلید (RSA، Ed25519 یا ECDSA، بدون passphrase) وارد می‌شه و پیامش فوراً پاک می‌شه.
  نشست بعد از ۱۰ دقیقه بی‌کاری، یا وقتی دکمه‌ی دیگه‌ای بزنی، بسته می‌شه.
- ⚖️ **Change Plan** و ⬇️/⬆️ **Prev/Next Plan**: عوض کردن پلن
  - 🔓 = هتزنر می‌گه اینجا موجود نیست؛ ممکنه باز هم بشه.
  - 💾 = دیسکش کوچیک‌تره و اجازه داده نمی‌شه.
  - اگه هتزنر قبول نکنه، سرور بدون تغییر دوباره روشن می‌شه.
  - دکمه‌ی 🔔 **Auto-switch when … is back** پلن رو زیر نظر می‌گیره و هر وقت موجود شد، خودکار سرور رو می‌بره روش.
- ⚙️ Manage ← 🔧 **Rebuild OS**، 📸 **Snapshots**، ✏️ **Rename**؛ 🌐 Network ← 💽 **Volumes**
- 🌐 Network ← **Floating IPs**: وصل و جدا کردن Floating IP. زیر هر IP که به این سرور وصله، دستورش هست
  (`sudo ip addr add <IP> dev eth0`) با دکمه‌ی 📋 Copy command؛ کپی کن و توی سرور اجراش کن تا سرور روی اون IP جواب بده.
  این دستور تا ریبوت بعدی می‌مونه.
- ⚙️ Manage ← 💾 **Backups** روشن/خاموش، 🔑 **Reset Password**
- ⚙️ Manage ← 💶 **Edit Price**: قیمت واقعی سرورهای قدیمی (ارزان‌تر از قیمت فعلی) رو وارد کن تا گزارش هزینه درست باشه.
- 🌐 Network ← 🧩 **Add to Panel**: سروری که قبلاً با `setup.sh` نود PasarGuard شده رو به پنل اضافه می‌کنه.
  پنل رو انتخاب کن و API key نود رو بفرست (آخر `setup.sh` چاپ می‌شه، یا در `/opt/pg-node/.env`).
  ربات سرتیفیکیت رو خودش از پورت 62050 نود می‌خونه و نود رو در پنل می‌سازه. فقط وقتی پنلی در `.env` تعریف شده باشه دیده می‌شه.

وقتی ربات منتظر تایپ توئه (Rename، Edit Price، اسم دلخواه سرور، API key نود، کنسول SSH):
اگه دکمه‌ی دیگه‌ای بزنی، اون انتظار لغو می‌شه و دکمه‌ی جدید اجرا می‌شه.
اگه ۱۵ دقیقه چیزی نفرستی هم خودش لغو می‌شه.
- ⚙️ Manage ← 🗑 **Delete Server**: دو دکمه داره: حذف کامل، یا **حذف ولی نگه داشتن IP**. در حالت دوم IPv4 سرور به‌صورت Primary IP آزاد توی اکانت می‌مونه (ماهانه هزینه داره) و موقع ساخت سرور جدید توی همون لوکیشن پیشنهاد داده می‌شه. با حذف سرور، زمان‌بندی‌ها، الرت‌ها و تنظیم ریست خودکارش هم پاک می‌شن.
- ⚙️ Manage ← 🛡 **Protection**: محافظت در برابر حذف و Rebuild. وقتی روشنه، هتزنر اجازه‌ی حذف یا نصب دوباره‌ی سیستم‌عامل رو نمی‌ده (نه از ربات، نه از مینی‌اپ، نه از کنسول). ربات هم قبل از حذف یا Rebuild می‌گه سرور محافظت داره و دکمه‌ی خاموش کردن محافظت رو نشون می‌ده.
- 🌐 Network ← 🔁 **Change IPv4**: به سرور یه IPv4 دیگه می‌ده. سرور حدود یک دقیقه خاموش می‌شه. انتخاب‌ها:
  - IP جدید و پاک کردن قبلی (معمولی)
  - IP جدید و نگه داشتن قبلی (قبلی آزاد می‌مونه و هزینه داره)
  - استفاده از یه IP نگه‌داشته‌شده توی همون لوکیشن
  اول IP جدید گرفته می‌شه، بعد سرور خاموش می‌شه؛ پس هیچ‌وقت همون IP قبلی برنمی‌گرده. اگه وسط کار خطا بشه، IP قبلی برمی‌گرده و سرور روشن می‌شه. اگه سرور نود پنل باشه، یادت می‌ندازه آدرسش رو توی پنل هم عوض کنی (DNS هم همین‌طور).

**ساخت سرور** (➕ Create Server)
- دسته ← (Intel یا ARM) ← پلن ← لوکیشن ← سیستم‌عامل ← IPv6 ← تعداد ← اسم ← تأیید
- کنار پلن‌ها: ✅n = در n لوکیشن موجوده، ⛔ = همه‌جا تموم شده. قیمت، ارزون‌ترین لوکیشن موجوده؛ اگه لوکیشن‌ها قیمت متفاوت داشته باشن «from» کنارش میاد.
- اگه ساخت چندتا سرور نصفه انجام بشه، 🔄 Retry فقط اون‌هایی رو می‌سازه که ساخته نشدن.
- مرحله‌ی سیستم‌عامل اسنپ‌شات‌های اکانت (📸) رو هم نشون می‌ده، فقط اون‌هایی که روی این پلن جا می‌شن.
- 🧬 **سرور از روی اسنپ‌شات**: Snapshots ← یه اسنپ‌شات ← **🧬 New server from this snapshot**. فقط پلن‌هایی که معماری‌شون یکیه و دیسکشون کمتر از دیسک سرور اصلی نیست نشون داده می‌شن؛ مرحله‌ی سیستم‌عامل رد می‌شه و اسم خودکار مثل `web-clone-10201107` می‌شه.
- 📍 اگه توی اون لوکیشن IP نگه‌داشته‌شده داشته باشی (از حذف سرور یا تغییر IP)، صفحه‌ی تأیید دکمه‌ی **📍 Use kept IP …** رو نشون می‌ده (فقط وقتی یه سرور می‌سازی).
- همه‌ی کلیدهای SSH اکانت روی سرور نصب می‌شن. اگه کلیدی نباشه، رمز root نشون داده می‌شه (فقط یک بار).

**ساخت نود PasarGuard با یک دکمه** (🧩 Create as node)
- در صفحه‌ی تأیید ساخت سرور، برای هر پنل یک دکمه‌ی **🧩 Create as node → <پنل>** هست (فقط برای سیستم‌عامل Ubuntu).
- سرور ساخته می‌شه و موقع اولین بوت خودش `setup.sh` رو بدون هیچ سؤالی اجرا می‌کنه (نصب نود، HAProxy، WireGuard، اوپتیمایزر و بقیه).
- ربات هر دقیقه چک می‌کنه؛ وقتی نود بالا اومد (معمولاً ۵ تا ۱۰ دقیقه؛ سرور بعد از نصب و اوپتیمایزر خودش یک بار ریبوت می‌شه و پنل دوباره وصلش می‌کنه)، خودش نود رو با IP، سرتیفیکیت و API key به پنل اضافه می‌کنه و خبر می‌ده.
- اگه پنل در دسترس نباشه دوباره امتحان می‌کنه؛ اگه پنل رد کنه (مثلاً اسم تکراری) یا تا ۴۰ دقیقه نود بالا نیاد، دلیل و API key رو می‌فرسته تا با 🧩 Add to Panel دستی اضافه کنی.
- یوزر و پسورد پنل فقط در `.env` همین ربات می‌مونه؛ روی نودها نوشته نمی‌شه.

**الرت ساخت خودکار** (برای پلنی که تموم شده)
1. روی پلن ⛔ بزن، بعد **🔔 Create automatically when back in stock**.
2. لوکیشن‌های قابل‌قبول رو **به ترتیب اولویت** بزن (1️⃣ 2️⃣ …)، بعد ✅ Continue.
3. سیستم‌عامل ← IPv6 ← اسم (🏷 Auto name یا اسم دلخواه) ← **🔔 Set Alert**.

ربات هر ۲ دقیقه موجودی رو چک می‌کنه. هر ۱۵ دقیقه هم بدون توجه به اعلام هتزنر واقعاً امتحان می‌کنه، چون تلاش ناموفق برای ساخت هزینه‌ای نداره.
به محض اینکه جا شد، سرور رو در اولین لوکیشن آزاد می‌سازه و اسم و IP رو می‌فرسته.
اگه جواب هتزنر وسط راه گم بشه و کلید SSH نداشته باشی، ربات می‌گه رمز نرسیده و با 🔑 Reset Password بگیرش.
تا وقتی ساخته نشه هیچ هزینه‌ای نداره.
اسم خودکار به شکل `cx53-nbg1-10082120` است: پلن، لوکیشن و زمان ساخت (ماه‌روزساعت‌دقیقه).

**Floating IP** (منوی اصلی ← 🌐 Floating IPs)
- روی هر IP بزنی انتخاب می‌شه و دستورش (`sudo ip addr add … dev eth0`) زیر لیست میاد؛ کنار IP هم دکمه‌ی 📋 Copy command هست.
  برای IPv6 اولین آدرس اون رنج (`…::1/64`) نوشته می‌شه. بعد از ساختن IP جدید هم دستورش نشون داده می‌شه.

**الرت تغییر پلن خودکار**
- وقتی پلن موجود شد، ربات خودش سرور رو جابه‌جا می‌کنه و خبر می‌ده. سرور چند لحظه خاموش می‌شه.
- اگه هتزنر ۴ بار با اینکه گفته موجوده قبول نکنه، ربات دیگه خودکار انجام نمی‌ده و فقط خبر می‌ده. این برای جلوگیری از خاموش/روشن شدن مکرر سروره.

**🌙 ریست خودکار شبانه** (🔔 Alerts & Schedules ← دکمه‌ی اول **🌙 Auto Reset**)
- هر شب سر ساعتی که خودت تعیین می‌کنی (پیش‌فرض **۵ صبح به وقت ایران**؛ همه‌ی ساعت‌های زمان‌بندی و ریست خودکار الان به وقت تهران حساب می‌شن)، ربات ترافیک هر سرور روشنی رو که
  - به **۹۰٪** سقفش رسیده (درصد قابل تغییره: ۷۵، ۸۰، ۸۵، ۹۰، ۹۵)، یا
  - با سرعت مصرف ۲۴ ساعت گذشته تا شب بعد از ۱۰۰٪ رد می‌شه،
  ریست می‌کنه. سرورها یکی‌یکی ریست می‌شن و هر کدوم دو بار چند دقیقه خاموش می‌شه.
- اول یه پیام میاد که کدوم سرورها ریست می‌شن، آخرش یه گزارش. اگه شبی هیچ سروری لازم نداشته باشه، پیامی نمیاد.
- دکمه‌ها: ⏸ خاموش/▶️ روشن کردن کل قابلیت، 🕔 **Time** (ساعت و دقیقه)، درصد، و 🖥 **Servers** برای بیرون گذاشتن هر سرور (✅ = شامل، ⛔ = بیرون).
- پیش‌فرض روشنه و همه‌ی سرورها شاملش هستن. سرور خاموش هیچ‌وقت دست نمی‌خوره.
- توی صفحه‌ی هر سرور ← ⏰ Reset Schedule هم یه دکمه‌ی 🌙 برای همون سرور هست. توی مینی‌اپ: تب Alerts، بخش Auto reset، و سوییچ Auto reset توی صفحه‌ی هر سرور.
- **ساعت جدا برای هر سرور**: ⏰ Reset Schedule ← **🕔 Auto reset time** ← ساعت ← دقیقه. اون سرور فقط سر ساعت خودش بررسی می‌شه، بقیه سر ساعت پیش‌فرض. با «↩️ Use the default time» برمی‌گرده. توی 🖥 Servers ساعتِ جدا کنار اسم سرور نوشته می‌شه. توی مینی‌اپ: صفحه‌ی سرور، «Auto reset time».
- وقتی کارهای خودکار متوقف باشن (⏸)، اون نوبت انجام نمی‌شه و خبر می‌ده.
- اگه ربات سر اون ساعت خاموش بوده و بیش از یک ساعت گذشته، اون شب انجام نمی‌شه و خبر می‌ده.

**🩺 سلامت اکانت‌ها** (منو ← 🩺 Health یا `/health`)
- ربات هر ۲ دقیقه با هر اکانت یه درخواست ساده می‌زنه. اگه توکن رد بشه (401، مثلاً اکانت بسته یا توکن باطل شده)، دسترسی رد بشه (403، مثلاً پروژه قفل شده) یا محدودیت تعداد درخواست بخوره (429)، **همون لحظه** پیام می‌ده. اگه جواب نده، بعد از دو بار پشت سر هم خبر می‌ده (که یه قطعی کوتاه پیام الکی نده). وقتی درست شد هم خبر می‌ده.
- اگه یه اکانت مشکل داشته باشه ربات دیگه موقع روشن شدن کلاً بسته نمی‌شه؛ فقط وقتی **همه‌ی** توکن‌ها رد بشن بسته می‌شه.
- هر ۵ دقیقه هم:
  - سروری که هتزنر **۳۰ دقیقه یا بیشتر قفلش کرده** و ربات خودش کاری روش انجام نمی‌ده (معمولاً یعنی کاری گیر کرده یا مسدود شده) رو خبر می‌ده، و وقتی باز شد هم خبر می‌ده.
  - اگه توی یه ساعت **۳ تا یا بیشتر کار ناموفق** (action با خطا) روی یه اکانت ثبت بشه، با لیستشون خبر می‌ده.
- صفحه‌ی 🩺 Health: وضعیت هر اکانت با تعداد درخواست باقی‌مونده‌ی این ساعت، سرورهای قفل، کارهای ناموفق ۲۴ ساعت گذشته.
- **📋 گزارش روزانه**: هر روز ساعت **۹ صبح به وقت ایران** (از همون صفحه عوضش کن، یا خاموشش کن): برای هر اکانت وضعیت دسترسی، تعداد سرورها (روشن، خاموش با اسم)، نزدیک یا بالای سقف ترافیک، قفل‌شده‌ها، کارهای ناموفق ۲۴ ساعت؛ نتیجه‌ی ریست خودکار دیشب، وضعیت توقف و تعداد الرت‌ها. دکمه‌ی «📋 Send the daily check now» هم همون موقع می‌فرستتش.

**⏸ توقف همه‌ی کارهای خودکار** (🩺 Health یا 🔔 Alerts & Schedules ← **⏸ Pause automations**)
- برای وقتی که حس می‌کنی هتزنر حساس شده. برای ۱، ۶ یا ۲۴ ساعت یا تا وقتی خودت ادامه بدی (▶️ Resume).
- متوقف می‌شن: ریست خودکار شبانه، ریست‌های زمان‌بندی‌شده (هر نوبتی که رد بشه خبر می‌ده)، الرت تغییر پلن و برگشت به پلن اصلی، و ساخت خودکار. الرت‌ها پاک نمی‌شن و بعد از ادامه دوباره کار می‌کنن.
- دکمه‌هایی که خودت می‌زنی کار می‌کنن، ریستی که در جریانه تموم می‌شه، و هشدارهای ترافیک و چک سلامت ادامه دارن.
- وقتی متوقفه، منوی اصلی و 🔔 Alerts می‌نویسن «⏸ Automations paused until …»؛ وقتی زمانش تموم بشه خودش ادامه می‌ده و خبر می‌ده.
- پیام‌های مشکل اکانت، قفل و کارهای ناموفق دکمه‌ی ⏸ Pause automations دارن.

**⏳ کارهای در جریان** (منو ← ⏳ Running now یا `/running`)
- کارهای خود ربات (ریست، تغییر پلن، تغییر IP) با مرحله‌شون، و کارهای در جریان هتزنر (اسنپ‌شات، تغییر پلن، روشن/خاموش…) با نوار و درصد. 🔄 Refresh برای دیدن پیشرفت. بعد از گرفتن اسنپ‌شات هم دکمه‌ی ⏳ Progress هست.

**هشدارهای خودکار ترافیک** (هر ساعت، نسبت به سقف ترافیک همون سرور)
- ۷۵٪: یک بار
- ۹۸٪: روزی یک بار
- بالای ۱۰۰٪: روزی یک بار (یعنی داری هزینه‌ی اضافه می‌دی)

**گزارش هزینه** (💸 Cost Report)
- سرورها، بکاپ، اسنپ‌شات، والیوم، IPها، اضافه‌ترافیک این ماه و پیش‌بینی آخر ماه، و سابقه‌ی ماه‌های قبل
- برای یک اکانت؛ اسم اکانت بالای صفحه نوشته شده و با دکمه‌های 🔑 می‌تونی اکانت دیگه رو ببینی. Snapshots و IPها هم همین‌طورن.

## مینی‌اپ (پنل داخل تلگرام)

یه صفحه‌ی **انگلیسی** با ظاهر مدرن (هم‌رنگ تم تلگرام، حالت تاریک هم داره) که از داخل ربات باز می‌شه
(دکمه‌ی **Panel** کنار جای تایپ، یا **📱 Open App** در `/start`). پنج تب پایین صفحه:
- **Overview**: تعداد سرورها، نزدیک یا بالای سقف ترافیک، هزینه‌ی ماهانه، الرت‌ها، پرمصرف‌ترین سرورها، نسخه‌ی ربات و آپدیت؛
  اگه اکانتی مشکل داشته باشه یا کارهای خودکار متوقف باشن، بالای صفحه «Attention» میاد (با دکمه‌ی Resume)؛ ردیف‌های **Health & safety** و **Running now**.
- **Servers**: جستجو با اسم/IP/پلن، مرتب‌سازی با ترافیک یا اسم، فیلتر نزدیک سقف و اکانت، نوار ترافیک، تگ نود پنل.
- **صفحه‌ی هر سرور**: حلقه‌ی ترافیک، دکمه‌های سریع (روشن/خاموش، ریست ترافیک، پلن کوچیک‌تر/بزرگ‌تر)، مشخصات، تغییر پلن
  (با ارتقای دیسک اختیاری و 🔔 الرت پلن)، زمان‌بندی ریست به وقت ایران، الرت‌های همون سرور، لاگ آخرین ریست.
  - **Network**: IPv4/IPv6 با کپی، فلوتینگ IPهای اکانت (Attach، Move here، Detach، **🗑 حذف**، دستور `sudo ip addr add …` با کپی،
    New IPv4/IPv6 = ساخت و وصل)، ولوم‌ها (ساخت با حجم دلخواه، وصل، جدا، حذف)، افزودن به پنل با API key،
    و دکمه‌ی **Change** کنار IPv4 (تغییر IP با همون سه انتخاب ربات).
  - **Manage**: تغییر اسم، قیمت دستی (یا برگشت به قیمت هتزنر)، بکاپ روشن/خاموش، ریست رمز root،
    سوییچ **Protection**، اسنپ‌شات‌های سرور (گرفتن، حذف، **New server** از روی اون)، نصب دوباره‌ی سیستم‌عامل،
    حذف سرور (باید اسمش رو تایپ کنی؛ با سوییچ «Keep the IP» برای نگه داشتن IPv4). با محافظت روشن، حذف و Rebuild غیرفعالن.
    رمزهای جدید و حذف سرور توی چت ربات هم فرستاده می‌شن.
- **Create**: اکانت، نوع، پلن (با موجودی و قیمت)، لوکیشن، سیستم‌عامل، IPv6، تعداد، اسم، 🧩 ساخت به‌عنوان نود؛
  برای پلن تموم‌شده «🔔 When in stock» با ترتیب لوکیشن‌ها. رمزها با دکمه‌ی کپی نشون داده می‌شن.
  اسنپ‌شات‌ها هم توی لیست سیستم‌عامل هستن، و اگه IP نگه‌داشته‌شده توی اون لوکیشن باشه انتخاب «IPv4» میاد.
- **Alerts**: زمان‌بندی‌های ریست، جابه‌جایی وقتی موجود شد، ساخت وقتی موجود شد؛ هرکدوم با دکمه‌ی لغو. ساعتِ جدای ریست خودکار هر سرور کنارش نوشته می‌شه.
- **More**: هزینه‌ی این ماه (هر اکانت جدا + جمع)، Floating IPs (ساخت، حذف، وصل به سرور با یه منو، دستور با کپی)،
  Primary IPs (ساخت، حذف)، Snapshots (همه‌ی اکانت‌ها، گرفتن از هر سرور، حذف، **New server**)،
  **Health & safety** (اکانت‌ها، توقف ۱/۶/۲۴ ساعت یا تا ادامه، گزارش روزانه با ساعتش و «Send it now»، قفل‌ها، کارهای ناموفق)،
  **Running now** (کارهای ربات و هتزنر با درصد؛ هر چند ثانیه خودش تازه می‌شه).
- حذف فلوتینگ IP: اگه به سروری وصل باشه، اول جدا می‌شه بعد حذف.
- کارهای طولانی (ریست، تغییر پلن، ساخت) توی پس‌زمینه انجام می‌شن؛ می‌تونی صفحه رو ببندی، نتیجه توی چت ربات هم میاد.
- فقط خودت (`ADMIN_ID`) می‌تونی ازش استفاده کنی؛ بقیه حتی اگه آدرس رو داشته باشن چیزی نمی‌بینن.
- همه‌ی کارهای ربات توی مینی‌اپ هم هست، جز **کنسول SSH** (فقط توی چت ربات).

راه‌اندازی مینی‌اپ: بخش «مینی‌اپ» در `README.md`.
