# Hetzner Server Manager Bot

ربات تلگرام (و مینی‌اپ) برای مدیریت سرورهای یک یا چند اکانت **Hetzner Cloud** از داخل تلگرام.
فقط یک نفر (ادمینی که آیدی‌اش در `ADMIN_ID` است) می‌تونه ازش استفاده کنه.
متن‌های داخل ربات و مینی‌اپ انگلیسی هستن؛ راهنما فارسیه.

## چی کار می‌کنه

- لیست سرورها با ترافیک، هزینه و وضعیت؛ روشن/خاموش، تغییر پلن، تغییر اسم، Rebuild، حذف، 🛡 محافظت در برابر حذف
- ♻️ **ریست ترافیک** (جابه‌جایی موقت روی پلن دیگه و برگشت)، زمان‌بندی‌شده و 🌙 **خودکار شبانه** برای سرورهای نزدیک سقف
- 🔔 الرت‌های موجودی: تغییر پلن یا ساخت سرور به‌محض موجود شدن پلن تمام‌شده
- ➕ ساخت سرور (با اسنپ‌شات هم)، 🔁 تغییر IPv4، نگه داشتن IP موقع حذف، Floating/Primary IP، ولوم، اسنپ‌شات، بکاپ
- 💸 گزارش هزینه (با اضافه‌ترافیک)، هشدار ترافیک، 🩺 چک سلامت اکانت‌ها، ⏸ توقف کارهای خودکار، ⏳ کارهای در جریان
- 💻 کنسول SSH داخل چت، 📱 مینی‌اپ کامل، آپدیت از داخل ربات
- (اختیاری) 🧩 ساخت و اضافه کردن سرور به‌عنوان نود **PasarGuard**

جزئیات هر قابلیت: [`docs/FEATURES.md`](docs/FEATURES.md)

> ⏰ فعلاً همه‌ی ساعت‌های زمان‌بندی و ریست خودکار به **وقت تهران** حساب می‌شن (`Asia/Tehran`).

## پیش‌نیازها

- سرور **Ubuntu/Debian** با دسترسی root (یه VPS کوچک کافیه) که به اینترنت و api.hetzner.cloud و api.telegram.org وصل باشه
- یه **ربات تلگرام**: از [@BotFather](https://t.me/BotFather) بساز (`/newbot`) و توکنش رو بردار
- **آیدی عددی تلگرام خودت**: مثلاً از [@userinfobot](https://t.me/userinfobot)
- **API Token هتزنر** با دسترسی **Read & Write**: کنسول Hetzner ← پروژه ← Security ← API tokens. برای هر پروژه (اکانت) یه توکن لازمه.

## نصب

روی سرور، با کاربر root:

```bash
apt-get update && apt-get install -y git
git clone https://github.com/s43id/hetz.git /opt/hetzner
cd /opt/hetzner
bash install.sh
nano .env
hetzner start
```

`install.sh` پکیج‌ها (python3، venv، git) رو نصب می‌کنه، `venv` می‌سازه، سرویس systemd به اسم `hetzner-bot` رو فعال می‌کنه
و دستور `hetzner` رو می‌ذاره. چندبار اجراش کنی اشکالی نداره.

بعد از `hetzner start` توی تلگرام به رباتت `/start` بفرست.

### تنظیمات (`.env`)

فایل `.env` موقع نصب از `.env.example` ساخته می‌شه (دسترسی فقط root). **هیچ‌وقت توکن‌ها رو توی git نذار.**

| کلید | توضیح |
|---|---|
| `TELEGRAM_TOKEN` | توکن ربات از BotFather (لازم) |
| `ADMIN_ID` | آیدی عددی تلگرام خودت؛ هرکس دیگه «⛔ Unauthorized» می‌گیره (لازم) |
| `HETZNER_ACCOUNTS` | `اسم:توکن,اسم2:توکن2` (لازم). اسم‌ها روی دکمه‌ها نشون داده می‌شن. یه اکانت: `personal:توکن` |
| `DEBUG_MODE` | `true` = لاگ کامل‌تر؛ پیش‌فرض `false` |
| `NODE_SETUP_URL` | (اختیاری) آدرس raw اسکریپت نصب نود برای 🧩 Create as node |
| `PANELS` | (اختیاری) اسم پنل‌های PasarGuard، مثلاً `main,backup` |
| `PANEL_<اسم>_URL` / `_USERNAME` / `_PASSWORD` | آدرس پنل و یوزر/پسورد یک ادمین sudo آن؛ `-` در اسم در کلید `_` می‌شه (`my-panel` ← `PANEL_MY_PANEL_URL`) |
| `PANEL_<اسم>_CORE_ID` | (اختیاری) شماره‌ی core config نود جدید؛ پیش‌فرض اولین core |
| `WEBAPP_DOMAIN` / `WEBAPP_PORT` | آدرس مینی‌اپ؛ خود `hetzner webapp` می‌نویسه‌شون |

بعد از هر تغییر `.env`: `hetzner restart` (یا `hetzner env` که ویرایش و ری‌استارت رو با هم انجام می‌ده).
کلیدهای نود (`NODE_SETUP_URL`، `PANELS`، `PANEL_...`) فقط برای قابلیت 🧩 نود PasarGuard لازمن؛ بدون اونا دکمه‌هاش دیده نمی‌شه و بقیه‌ی ربات کار می‌کنه.

### منطقه‌ی زمانی

ساعت‌هایی که ربات نشون می‌ده با `hetzner tz Europe/Berlin` (هر منطقه‌ای) عوض می‌شه. زمان‌بندی ریست‌ها فعلاً ثابت به وقت تهران است.

## مینی‌اپ (اختیاری)

پنل گرافیکی داخل تلگرام که از دکمه‌ی **Panel** کنار جای تایپ باز می‌شه. به یه دامنه با HTTPS نیاز داره:

1. برای یه ساب‌دامین (مثلاً `hetzner.example.com`) یه رکورد **A** به IP سرورت بساز. اگه دامنه روی Cloudflare است، **DNS only** باشه (ابر خاکستری).
2. روی سرور:
   ```bash
   hetzner webapp hetzner.example.com
   ```
   این دستور با certbot گواهی SSL رایگان می‌گیره (پورت 80 باید آزاد باشه)، یه پورت رندوم انتخاب می‌کنه، تنظیمات رو توی `.env` می‌نویسه و ربات رو ری‌استارت می‌کنه.
3. اگه فایروال داری (روی سرور یا توی کنسول هتزنر)، پورت **80** و پورت رندومی که چاپ شد (TCP) رو باز کن.
4. توی تلگرام `/start` بزن؛ دکمه‌ی «Panel» ظاهر می‌شه.

گواهی خودش تمدید می‌شه. فقط خودت (`ADMIN_ID`) می‌تونی از مینی‌اپ استفاده کنی.

## آپدیت

- **از داخل ربات**: `/update` ← **⬆️ Update** ← **✅ Yes**. ربات چند ثانیه ری‌استارت می‌شه و نتیجه رو می‌گه. ↩️ Roll back برای برگشت به نسخه‌ی قبل.
- **روی سرور**: `hetzner update` و برای برگشت `hetzner rollback`.

وقتی ریست یا تغییر پلنی در جریانه آپدیت نزن؛ ری‌استارت قطعش می‌کنه.

## دستور `hetzner`

| دستور | کار |
|---|---|
| `hetzner` | منوی تعاملی |
| `hetzner start` / `stop` / `restart` | روشن / خاموش / ری‌استارت |
| `hetzner status` | وضعیت سرویس |
| `hetzner logs` | لاگ زنده (خروج با Ctrl+C) |
| `hetzner env` | ویرایش `.env` و ری‌استارت |
| `hetzner update` / `rollback` | آپدیت / برگشت |
| `hetzner tz <منطقه>` | منطقه‌ی زمانی نمایش |
| `hetzner webapp <دامنه>` | راه‌اندازی مینی‌اپ |
| `hetzner uninstall` | حذف سرویس (کد می‌مونه؛ داده‌ها فقط با تأیید پاک می‌شن) |

## داده‌ها

ربات دیتابیس نداره؛ وضعیت‌ها در فایل‌های JSON کنار کد ذخیره می‌شن (داخل git نمی‌رن): الرت‌ها (`plan_watches.json`، `create_watches.json`)،
زمان‌بندی‌ها (`reset_schedules.json`)، ریست خودکار (`auto_reset.json`)، توقف کارها (`automation.json`)، سلامت (`health.json`)،
قیمت‌های دستی (`price_overrides.json`)، سابقه‌ی اضافه‌ترافیک (`overage_history*.json`)، نودها (`node_setups.json`).
برای بکاپ همین فایل‌ها و `.env` رو کپی کن.

## امنیت

- فقط `ADMIN_ID` می‌تونه از ربات و مینی‌اپ استفاده کنه؛ مینی‌اپ initData امضاشده‌ی تلگرام رو چک می‌کنه.
- توکن‌ها فقط در `.env` هستن. رمز root سرورها فقط داخل چت نشون داده می‌شه و ذخیره نمی‌شه.
- کنسول SSH یوزر و رمز یا کلید رو می‌گیره و پیامش رو فوراً پاک می‌کنه؛ توی حافظه‌ی ربات فقط تا پایان نشست می‌مونه.
- برای هر اکانت هتزنر توکن مجزا و فقط به اندازه‌ی نیاز بساز؛ اگه جایی لو رفت از کنسول هتزنر حذفش کن.

## تست و توسعه

```bash
python3 -m venv venv && venv/bin/pip install -r requirements.txt
venv/bin/python dev/run_tests.py
```

تست‌ها کاملاً آفلاین‌اند (هتزنر و تلگرام ساختگی) و به هیچ توکنی نیاز ندارن. هر تغییر باید `VERSION` رو بالا ببره و یه بخش `## x.y.z` به بالای `CHANGELOG.md` اضافه کنه (یه تست این رو چک می‌کنه).
CI در `.github/workflows/tests.yml` تست‌ها رو با پایتون ۳.۱۰ و ۳.۱۲ اجرا می‌کنه.
